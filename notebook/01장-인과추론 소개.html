1.2 인과추론의 목적

인과추론의 주된 목적은 처치(Treatment)가 결과(Outcome)에 미치는 효과를 추정하는 것입니다. 이를 통해 특정 정책이나 마케팅 캠페인이 실제로 효과가 있었는지, 또는 앞으로 어떤 결정을 내려야 할지 판단할 수 있습니다.

1.3 머신러닝과 인과추론

머신러닝은 주로 ’예측(Prediction)’에 중점을 둡니다. 반면 인과추론은 ’반사실적 질문(Counterfactual Question)’에 답하고자 합니다. 예측 모델은 데이터의 패턴을 파악하지만, 인과 모델은 데이터가 생성되는 과정(Data Generating Process)을 파악합니다.

1.4 연관관계와 인과관계

상관관계는 인과관계를 의미하지 않습니다(Correlation is not causation). 두 변수 사이에 상관관계가 있더라도, 그것이 반드시 직접적인 인관관계를 의미하지는 않으며, 제3의 변수(교란 변수)에 의한 것일 수 있습니다.

1.4.1 처치와 결과

인과관계에서 독립변수 역할을 하는 것을 ‘처치(T)’, 종속변수 역할을 하는 것을 ’결과(Y)’라고 부릅니다.

1.4.2 인과추론의 근본적인 문제

동일한 개체에 대해 처치를 가했을 때의 결과(\(Y_1\))와 가하지 않았을 때의 결과(\(Y_0\))를 동시에 관찰할 수 없다는 점이 인과추론의 가장 큰 어려움입니다. 관찰되지 않은 결과는 ’잠재적 결과(Potential Outcome)’라고 합니다.

1.4.8 인과 추정량

우리가 알고자 하는 평균적인 인과 효과를 추정량(Estimand)이라고 합니다. 대표적으로 전체 집단에 대한 평균 처치 효과(ATE), 처치를 받은 집단에 대한 효과(ATT) 등이 있습니다.

1.4.9 인과 추정량 예시

pd.DataFrame(
    dict(
        i=[1, 2, 3, 4, 5, 6],
        y0=[200, 120, 300, 450, 600, 600],
        y1=[220, 140, 400, 500, 600, 800],
        t=[0, 0, 0, 1, 1, 1],
        x=[0, 0, 1, 0, 0, 1],
    )
).assign(
    y=lambda d: (d["t"] * d["y1"] + (1 - d["t"]) * d["y0"]).astype(int),
    te=lambda d: d["y1"] - d["y0"],
)

).assign(
    y=lambda d: np.where(d["t"] == 1, d["y1"], d["y0"]).astype(int),
